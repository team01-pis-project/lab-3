## Описание проекта

Программная реализация расчёта метрик Холстеда для оценки сложности, трудоёмкости и надёжности программного обеспечения. Работа содержит три задания, охватывающих теоретическую оценку ошибок, структурный анализ и оценку рейтинга программиста.

Вариант: 1
Язык: Java
Среда: IntelliJ IDEA

## Задания

- Задание №1: Оценка потенциального числа ошибок;
- Задание №2: Структурные параметры и трудозатраты;
- Задание №3: Рейтинг программиста;
